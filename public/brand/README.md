# GitMint logo assets

## Vector files
- `icon.svg` — square app mark with mint tile.
- `leaf.svg` — transparent leaf symbol.
- `wordmark-light.svg` — horizontal lockup for light backgrounds.
- `wordmark-dark.svg` — horizontal lockup for dark backgrounds.
- `wordmark.svg` — default web-ready wordmark with tagline.
- `favicon.svg` — square favicon.

## Raster files
- `16x16.png` through `1024x1024.png` — square icon sizes for web and app use.
- `favicon.png` — 32px PNG favicon.
- `wordmark-light-2x.png` and `wordmark-dark-2x.png` — 2x wordmark exports.

The SVG files are standalone and use no external images, fonts, or stylesheets. The wordmarks use a system sans-serif font stack.
