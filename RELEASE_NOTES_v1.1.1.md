## What's new

- GitMint checks the latest stable GitHub release when the app opens.
- When a newer version is available, a small dismissible banner links to its release page.
- Settings now includes a manual **Check now** action and the current app version.
- Removed the small version badge beside the GitMint logo.

## Install

Download `GitMint_1.1.1_aarch64.dmg` for Apple silicon Macs. This build is ad-hoc signed and not notarized with an Apple Developer ID, so macOS may show a security warning when opening it.
