# Security policy

GitMint is a public beta. Please report suspected vulnerabilities privately rather than posting exploit details in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/filipmoco0/GitMint/security/advisories/new) for this repository. If private reporting is unavailable, contact the maintainer privately through their [GitHub profile](https://github.com/filipmoco0).

Include the affected version, steps to reproduce, and potential impact. Do not include access tokens, private repository contents, or other people's personal data. The maintainer will acknowledge reports and coordinate a fix before public disclosure where practical.

Security fixes are provided for the latest beta release on a best-effort basis.
