## What's new

- **Search GitHub:** Find public repositories from GitMint and browse more results as you go.
- **Repository details:** Open a repository to see its description, default branch, and last update, then clone it, copy its URL, or open it on GitHub.
- **Readable READMEs:** Repository documentation now renders as formatted Markdown, including headings, tables, code blocks, and sanitized HTML such as centered logos.
- **Repository assets:** Relative README images and links resolve to files in that repository.

## Install

Download `GitMint_1.1.0_aarch64.dmg` for Apple silicon Macs. Open the disk image and drag GitMint to Applications.

This build is ad-hoc signed and is not notarized with an Apple Developer ID. macOS may show a security warning the first time you open it.

## Known limitations

- This release targets Apple silicon Macs.
- GitHub repository search requires signing in to GitHub.
- Pull requests and merge workflows are not included.
